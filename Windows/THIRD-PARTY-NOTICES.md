# Windows package dependencies

The bridge's source is covered by the repository's MIT license. The executable also bundles:

- **CPython**, Python Software Foundation License. https://docs.python.org/3/license.html
- **Tcl/Tk**, Tcl/Tk license. https://www.tcl-lang.org/software/tcltk/license.html
- **SQLite**, public domain. https://sqlite.org/copyright.html
- **PyCryptodome 4.6.0**, BSD/public-domain components. https://www.pycryptodome.org/src/license
- **PyInstaller 6.22.3 bootloader**, GPL with the exception permitting bundled applications under their own licenses. https://pyinstaller.org/en/stable/license.html

PyCryptodome metadata is retained in `_internal`; available upstream license texts are copied into `licenses`. The application icon is the existing project artwork converted to Windows ICO format.
